# AI session logs

- `session-main.jsonl`: the main Claude Code session, exported as the tool stores it.
- `subagents/agent-*.jsonl`: the sub-agent sessions that session started.
- `*.md`: a plain, mechanical rendering of the matching `.jsonl` file (nothing summarised or left out, except binary image data).

One change was made to the files: the account owner's personal name and email address
were replaced with `[name redacted]` and `[email redacted]` before publishing. Nothing
else was edited, removed or reworded.
